TV Boxsets: Kodi repository

Alpha build. Current version: 0.21.6.

  1. Download repository.tvboxsets-1.2.0.zip (the repository add-on).
  2. In Kodi: Settings > Add-ons > Install from zip file and choose that file.
  3. Then Add-ons > Install from repository > TV Boxsets Repository to install TV Boxsets. Kodi will offer future updates by itself.

Source code, tests and release zips with checksums: https://github.com/jamesbockholt1975-cmd/kodi-tv-boxsets

This page exists so the folder can be hosted on drag-and-drop hosts; Kodi only uses addons.xml and the files under zips/.
